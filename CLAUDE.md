# qtng/chunom

The Chunom site (dictionary of Chữ Nôm, decks, writer, font catalogue, glyph votes), served at `chunom.org/chunom/`: plain HTML and JavaScript with Bootstrap, no build step.
All instructions (the four repositories and how they belong together, URL rules, translation, and everything about this repository) are in the private repository `qtng/chunom-private`, file `CLAUDE.md`, section "The public repositories"; attach it with `add_repo` when a session starts here. Nothing technical is written in this public file.
Always: Inside the Chunom site root-relative paths (`/chunom/js/…`), from there to qatt.org absolute URLs (`https://qatt.org/…`); no cache busters unless a copy is kept for ever; texts of the interface are translated with `data-vi`; tools and SQL are not here.
